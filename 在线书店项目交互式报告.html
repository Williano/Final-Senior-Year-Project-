在线书店销售系统设计与实现

本报告旨在交互式地展示一个基于现代Web技术栈（Django, Vue.js）开发的在线书店项目。应用旨在提供一个功能完善、用户体验良好的电子商务平台，涵盖从用户浏览、购物车到订单管理的全流程。

课题目的

开发一个功能完备的在线书店平台，实现用户友好的图书销售流程，并为管理员提供高效的后台管理工具，以验证和应用所学的软件工程知识。

课题意义

将理论知识与实践相结合，掌握Web全栈开发的核心技能。项目成果不仅是一个可运行的系统，更是对软件开发生命周期的全面演练。

关键词

Django Vue.js MySQL 在线书店

技术架构

系统采用前后端分离的现代架构模式。这种设计提高了开发效率、可维护性和系统的可扩展性，使得各层级职责分明，易于独立开发和部署。

🖥️

前端

Vue 3

构建用户界面的渐进式框架，负责视图渲染、用户交互和状态管理。

↔️
⚙️

后端

Python 3.11 + Django 4.2

提供业务逻辑、API接口和数据处理。Django的高效开发特性保证了后端的稳定性和安全性。

↔️
🗃️

数据库

MySQL 8.0

作为关系型数据库，负责持久化存储所有业务数据，如用户信息、商品、订单等。

核心功能

系统功能围绕用户和管理员两条主线设计。用户端注重流畅的购物体验，管理端则强调操作的便捷与高效，共同构成一个完整的电商生态。

🛍️前台用户功能

用户中心

登录、注册、修改个人信息（密码、收货地址）。

图书浏览与搜索

首页推荐（条幅、热销、新品）、按分类浏览、关键词搜索、查看图书详情。

购物车管理

添加商品、修改数量、删除商品、合并付款。

订单系统

下单支付、查询个人订单、确认收货、商品评价。

🛠️后台管理功能

订单管理

按状态查询订单、修改订单状态（发货、完成）、删除订单。

用户管理

查询所有用户、新增用户、修改用户信息及密码、删除用户、管理用户角色和权限。

商品管理

图书类目管理（增删改查）、图书信息管理（增删改查）、库存管理。

内容与运营管理

系统公告管理、首页轮播图管理、运费模板管理、用户评价审核。

系统设计

良好的系统设计是项目成功的基石。本项目的数据库设计遵循第三范式，确保了数据的结构化和一致性，并通过模块化设计实现了功能的高内聚和低耦合。
